### Changes
- This fixes the performance issues in high concurrency observed in high concurrency region.
- The following are the new features 
 - V1 engine is turned on by default (new block manager, scheduler, enginecore, chunked prefill )
 - Zero Overhead Prefix Caching
 - FlashAttention 3
 - Cuda graphs that capture more/larger variants

### Breaking changes
- Due to cuda graphs and chunked prefill, VLLM out of box is optimized for higher throughput and lower latency.
  - We observe better TTFT across the board.
  - But, for longer prompt (RAG, Heavier RAG) we expect higher latency at the cost of higher throughput.
  - We are switching to SGLang runtime for models effected by this.
- The following metrics have been deprecated:
  - ```vllm.avg_generation_throughput_toks_per_s```
  - ```vllm.avg_prompt_throughput_toks_per_s```
  - Replacement e.g.
    - ```vllm.generation_tokens_total[$granularity].rate().grouping().mean()```
- This is no longer relevant due to new architecture.
```vllm:num_requests_swapped and vllm:cpu_cache_usage_perc```
  - No replacement 
- Nvidia Driver version: 550.76+
