Patches applied to sanity scripts during the run:
1. `openai_chat_consistency_check.py:22` — removed `ignore_eos: True` (SMG/Harmony rejects with HTTP 400)
2. `openai_api_parser.py:53` — `get_generated_text` falls back to `reasoning_content` when `content` is empty
3. `loogle_eval.py:119` — same `reasoning_content` fallback for hyps extraction

### Breaking Changes

1. Reasoning field renamed `reasoning` → `reasoning_content`. Clients reading `delta.reasoning` will see it empty.
2. `tool_choice: "required"` needs an explicit prompt. Vague prompts can leak raw Harmony tokens into `content`
