## Add vLLM runtime for OpenAI Whisper Large V3 Turbo (first ASR/audio-to-text runtime release)
- Model supported for import
  - openai/whisper-large-v3-turbo

### Tag & Source
<!-- Mention Git tag and base branch/tag used -->
- Engine image: `fra.ocir.io/idqj093njucb/vllm-openai:v0.19.0-audio`
- PRs:
  - #1132 — vLLM `ClusterServingRuntime` for whisper-large-v3-turbo (runtime YAML + Helm values)
  - #1218 — model-agent: detect `AUDIO_TO_TEXT` capability for ASR model architectures

---

### Changes
<!-- List all relevant code or behavior changes -->
- Change 1: Add `vllm-whisper-large-v3-turbo` ClusterServingRuntime supporting H100-1, A100-80G-1, A100-40G-1, A10-1 (single-card only; multi-GPU shapes deferred until DP is supported in OME).
- Change 2: Set engine image to `v0.19.0-audio` (vLLM fork with audio pipeline; off the standard vLLM release track).
- Change 3: model-agent `config_parser.go` — detect `AUDIO_TO_TEXT` capability from model architecture strings (`WhisperForConditionalGeneration`, `Wav2Vec2`, `HuBERT`, `ForTC`, `ForSpeechToText`).
- Change 4: Runtime args: `--dtype=float16 --max-model-len=-1 --tensor-parallel-size=1`.
- Known limitation: SMG 1.4.1 router does not forward `POST /v1/audio/transcriptions` (multipart/form-data). Requests must go directly to the engine port; router-path transcription returns 404. Tracked for fix in a future SMG release.

### Known Limitations
<!-- Note any known bugs, regressions, or gaps -->
- Engine image `v0.19.0-audio` is a custom fork; it is not on the standard vLLM release cadence and must be tracked separately for updates.
- **SMG does not yet support routing audio/multipart requests** (`POST /v1/audio/transcriptions`). The runtime has no `routerConfig` for this reason — once SMG adds audio routing support, a router container will be added to this runtime.
