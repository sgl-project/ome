### Known Limitations
<!-- Note any known bugs, regressions, or gaps -->
BFCL evaluation updates the API so the bfcl-eval is conducted with the new API:

```python
export LOCAL_SERVER_ENDPOINT="$VLLM_ENDPOINT"
export LOCAL_SERVER_PORT="$VLLM_PORT"
```

BFCL evaluation is not backward compatible with the previous API:

```python
export VLLM_ENDPOINT="$VLLM_ENDPOINT"
export VLLM_PORT="$VLLM_PORT"
```
