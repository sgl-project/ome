### Known Limitations
<!-- Note any known bugs, regressions, or gaps -->
- The reasoning models gpt-oss-20b and gpt-oss-120b use tokens for generating reasoning content, which is in the `response.choices[0].message.reasoning_content` for vllm and sglang. If the token usage exceeds the output token limit, users will receive an empty response. The dp-api server should be prepared to handle this scenario.
- For gpt-oss-20b and gpt-oss-120b, the measured TTFT (Time To First Token) benchmark is based on the first reasoning content token, which is not first token of content. Users may experience a significant delay before receiving the first token of content in the response.
