### Changes
<!-- List all relevant code or behavior changes -->
- Change 1: Introduce diffusion runtime support for QwenImage/QwenImagePlus and QwenImageEdit/QwenImageEditPlus.
- Change 2: Enable VAE tiling for large image decoding (supports 4K–8K outputs with increased latency).
- Change 3: Add A100-40G support via `--dit-layerwise-offload` to stream transformer blocks to GPU.

### Known Limitations
<!-- Note any known bugs, regressions, or gaps -->
- Increasing GPU count has minimal impact on latency but increases throughput proportionally.
- QwenImage models natively support 512px–2048px outputs; VAE tiling enables 4K–8K decoding with higher latency.
- A100-40G requires `--dit-layerwise-offload` to keep one transformer block resident on GPU while streaming weights.
- Input image size has minimal impact on QwenImageEdit/QwenImageEditPlus end-to-end latency.
